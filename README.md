
# 🐯 TigerCave Finance Hub

A comprehensive, high-fidelity static frontend clone of a modern Indian fintech application (inspired by platforms like Zerodha, Dhan, and Angel One). This project served as my foundational entry point into managing complex UI states, modern styling engines, and component layout design.

## 📌 PROJECT VISION & OBJECTIVE

The goal of TigerCave Finance Hub was to map out the entire customer-facing architecture of a digital investment platform. It includes highly dense financial dashboard mockups covering:
* **Equity Market Metrics:** Real-time visualization components for tracking domestic share prices.
* **Investment Vehicles:** Dedicated layouts for managing Mutual Funds, upcoming IPO assets, and Digital Gold Savings.
* **Derivative Desks:** Specialized workspace UI for Futures & Options (F&O) trading.
* **User Acquisition:** Static user registration, pricing transparency modules, and "Create Free Account" authentication landing pages.

## 🛠️ MODERN FRONTEND STACK

* **Framework:** React.js (Vite Build System)
* **Language:** TypeScript (Strict Type Safety)
* **Styling Engine:** Tailwind CSS + ShadCN UI (High-fidelity, accessible component primitives)
* **Package Manager:** Bun / NPM

## 🚀 ARCHITECTURAL TAKEAWAYS

* **Status:** Foundational frontend UI layout complete.
* **Engineering Milestone:** This repository served as my sandbox for mastering component modularity, learning modern component design principles with AI-assisted workflows (Lovable dev system), and understanding how to structure high-density data grids typical of trading desks.
